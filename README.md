# Engineering Storage Bot

Telegram-бот для небольших инженерных проектов.

Функции:
- несколько проектов на пользователя;
- произвольное дерево папок;
- загрузка файлов;
- автоматическая история версий файла по имени;
- получение любой старой версии;
- комментарий и масса для каждой версии;
- количество экземпляров;
- компоненты без файлов;
- записки;
- рекурсивный подсчёт массы папки и проекта;
- необязательный лимит массы проекта.

## Запуск

1. Установите Python 3.12+.
2. Создайте Telegram-бота через @BotFather и получите token.
3. Откройте терминал в папке проекта.
4. Создайте виртуальное окружение:

Windows:
    python -m venv .venv
    .venv\Scripts\activate

macOS/Linux:
    python3 -m venv .venv
    source .venv/bin/activate

5. Установите зависимости:
    pip install -r requirements.txt

6. Скопируйте `.env.example` в `.env` и вставьте токен:
    BOT_TOKEN=123456:ABC...

7. Запустите:
    python bot.py

8. Откройте бота и отправьте `/start`.

SQLite-файл создаётся автоматически.

## Важное про файлы

Приложение хранит Telegram `file_id`, а не копию файла на локальном диске.
Это удобно для MVP: старую версию бот повторно отправляет через Telegram.

## Поведение версий

Если в выбранной папке уже есть файл с тем же именем, новая загрузка автоматически
считается следующей версией этого логического файла.

Для принудительного добавления версии можно открыть файл и нажать «Новая версия».


## Модель детали

В текущей версии отдельная кнопка добавления файла убрана. В папке используется одна кнопка `🔩 + Деталь`.
При создании детали задаются название, масса и количество, затем бот предлагает `📎 Приложить файл` или `— Без файла`.
Если файл приложен, следующие загрузки через карточку детали сохраняются как v2, v3 и т.д.; любую версию можно скачать.
